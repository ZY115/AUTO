# 记忆历史与学习任务状态：受控 pilot

## 要分开的两个问题

这个实验把两件事分开：

1. **完整历史记忆**：保留一幕中出现过的全部标签及顺序；
2. **任务状态抽象**：把对未来动作价值完全等价的历史放进同一状态。

每幕从 `A..E` 中取 `n` 个零件，按所有 `n!` 个排列中的均匀分布逐个呈现。呈现结束后工作台清空，智能体只能根据内部记忆选择 `X` 或 `Y`。真实规则固定为：`A` 在 `B` 前则选 `X`，否则选 `Y`；正确奖励 1，错误奖励 0，随后终止。

最终物理观察和已检查数量对所有排列都相同。区别只能来自历史表示。因为每幕只有一次终止动作，严格说它是带历史输入的 contextual bandit，而不是导航实验。

## 第一轮：先给正确压缩

比较四种表示，控制算法均为一步表格 Q-learning：

| 方法 | 最终决策状态 |
|---|---|
| `full_history` | 完整排列，如 `ACB` |
| `correct_automaton` | DFA 依次读标签，输出 `A-first` / `B-first` |
| `correct_handwritten` | 手写变量记录首先出现的 A/B |
| `progress_count` | 只记录已经检查了 n 个零件 |

Q 更新用 `alpha=1/N(state, action)`，即逐状态-动作样本均值；探索率恒为 `epsilon=0.10`。每幕每个 RL 方法恰好更新一次。自动机与手写程序是相互独立的代码路径，但应该产生完全相同的状态和学习曲线。

`progress_count` 是信息不足的诊断项，不是主要竞争方法。在所有排列均匀且评估不保留额外记忆时，任何固定最终动作的准确率都恰为 0.5。

主要比较 `correct_automaton` 与 `full_history`。`n=3,4,5` 时完整历史数为 6、24、120，正确任务状态始终只有 2。该比例只是机制操纵，不预先当作速度倍数。

## 第二轮：从反馈学习压缩

先验只说明正确动作由某两个零件的先后决定，不说明是哪一对，也不说明哪个方向对应 X。对 n 个零件，初始候选是全部 `n(n-1)` 条有向规则：

```text
u 在 v 前 -> X；否则 -> Y
```

智能体知道自己的动作和 0/1 奖励，所以每幕都能恢复该历史的正确标签：成功时标签等于所选动作，失败时等于另一个动作。反馈是确定且无噪的；所有与标签矛盾的候选被排除。

比较四种方法：

| 方法 | 做法 |
|---|---|
| `full_history` | 不推断规则，始终逐排列学习 |
| `immediate_use` | 按当前全部候选对历史的预测向量分组，并立即共享 Q 证据 |
| `delayed_use` | 同样排除候选，但候选唯一之前始终逐排列学习；唯一后才压成两组 |
| `direct_rule` | 直接按候选规则的多数预测选动作，不再套一层 Q-learning |

若当前候选集为 `V`，历史 `h` 的签名是：

```text
(rule(h) for rule in V)
```

签名相同的两条历史在每个仍可能为真的规则下动作都相同。真实规则从不被确定反馈排除，因此这种共享不会合并真实正确动作不同的历史。候选减少时，分区只能合并，不能拆分。

每条经验一直保留其完整历史下的奖励和访问次数。需要合并状态时，把这些充分统计量求和；不重放旧转移，也不增加 Q 更新次数。样本均值 Q 更新使该合并在代数上无损。原始结果另外记录：

- 在线候选检查次数；
- 直接规则法为每幕决策计算候选预测的次数（候选唯一后仍需一次）；
- 重建分区时的规则预测次数；
- 重建时扫描的历史和统计单元数；
- Q 更新次数及 CPU 时间。

`direct_rule` 对照不能因为结果太强而删除。若它最好，正确结论是这个小而确定的规则族直接做候选消除已经足够。

## 冻结协议和指标

- 零件数：3、4、5；真实规则始终为 `A<B -> X`。
- 训练序列：每幕 iid 均匀抽一个完整排列。
- 正式重复：每个规模 400 个种子，每个种子 5,000 幕。
- 配对：同一 `(n, seed)` 的所有方法共用完全相同的排列、探索判定与随机动作流。
- 评估：冻结策略，枚举全部 `n!` 条历史，不更新 Q、候选集或记忆；Q 并列按随机并列的期望计分。
- 评估频率：1–200 幕每幕；205–1,000 每 5 幕；1,020–5,000 每 20 幕；另含第 0 和最终点。
- 主速度量：首次在记录点达到且其后保持 95% 精确准确率的幕数；未达到者按 5,000 幕计入 RMST。
- 第二轮的直接机制量：从第 1 幕到唯一识别规则的那一幕，累加立即法与延迟法在 iid 历史下的精确策略准确率差。第 `t` 幕动作使用反馈 `t-1` 后的策略，故累加曲线的 `0..I-1` 点。这个量专门捕捉完整识别前很短的共享窗口，不能替代全程速度量。
- 辅助量：末点精确准确率、归一化曲线损失 `integral(1-accuracy)/budget`、状态数、规则识别幕数和上述计算成本。
- 不确定性：种子为独立单位，方法间按种子配对，自助法 95% 区间。

## 能回答和不能回答的范围

这个 pilot 能回答：在完整历史本来就有足够信息时，已知的正确合并是否提高样本效率；在受限有序对规则族中，发现部分可靠结构后立即共享是否比等到唯一识别更好；获得和整理结构需要多少显式操作。

它不能验证主动探索。检查顺序由环境提供，反馈准确，而且二选一失败会直接暴露正确标签；方法没有选择证据采集路线。它也不验证导航技能复用、不可逆长程前缀、噪声下的结构学习或通用自动机归纳。成功结果只能作为“历史压缩”这一局部机制的证据。
