# Stage 8 第十三步：第三次尝试可学习的乘积势，追平但没有追上

前两次尝试都失败，病因各自诊断清楚。这一次按诊断改设计，做出了三次里最好的一个，**首次成功阶段快 1.19 倍，区间 [1.15, 1.23]，但总账只是持平，1.01 [0.99, 1.04]。到特权乘积势的 3.74 倍差距没有缩小。**

## 1. 设计

前两次的病因是互补的：反向计数版在第一次成功之前没有数据，所以那一段它就是深度势；计算版把"已知最深处"当目标，势在那里取 0，把 agent 钉在那一格上。

而深度势在 frontier 同样取 0 却没事，区别是它**没有空间分量**，所以不会产生空间上的吸引子。

于是第三版把势拆成两半：

- **空间一半**指向"这个任务状态下还没试过的事件"最近的格子，距离在学到的地图上算。目标会随证据移动，所以不会变成吸引子。
- **深度一半**是"还欠几个事件"，第一次成功之前用已见最深加一的乐观估计。

两半都只用 agent 自己观测得到的东西：地图边每走一步免费得到一条，任务深度由进度反馈给出。

## 2. 两个实现错误，都会让结论完全相反

**错误一，用"每事件平均步数"做单位换算。** 为了把深度分量换成步数，我用了总步数除以总事件数。这个量在早期极不稳定：第一个事件之前走了几百步，它就是几百，势直接被吹爆。所有配置在开发集上全线崩溃，看起来像是这个设计不成立。

修法是取消换算：深度一半保持事件为单位，空间一半保持步数为单位，两个尺度自然吸收单位差。

**错误二，两半共用一个尺度。** 空间分量的量程比深度分量大，共用尺度时深度分量被压在自己最优值的五分之一。分开之后深度分量的最优值回到 0.07，和纯深度势一致。

修好之前 guided 的最好成绩是 9,094，修好之后是 4,273。**这两个数的差别全部来自实现，不是设计。**

## 3. 确认结果

12 个任务 × 32 个新种子，每臂 384 条运行，全部达标。

| 势 | 达标步数 | 首次成功 | 首次成功后 | AUC |
| --- | --- | --- | --- | --- |
| 不塑形 | 28,872 | 5,084 | 23,788 | 0.906 |
| 深度势 | 4,331 | 1,113 | 3,218 | 0.990 |
| guided | 4,273 | 933 | 3,340 | 0.991 |
| 反向计数版 | 10,911 | 1,119 | 9,792 | 0.972 |
| 特权乘积势 | 1,143 | 264 | 879 | 1.000 |

按任务成块的配对比较：

| 比较 | 比值 | 95% 区间 |
| --- | --- | --- |
| guided 相对深度势，总账 | 1.01 | [0.99, 1.04] |
| guided 相对深度势，**只看首次成功之前** | **1.19** | **[1.15, 1.23]** |
| 反向计数版相对深度势 | 0.40 | [0.33, 0.48] |
| 特权乘积势相对深度势 | 3.79 | [3.15, 4.37] |
| 特权乘积势相对 guided | 3.74 | [3.10, 4.31] |

## 4. 买到的和还回去的

空间分量确实有效，而且效果被分辨出来了：首次成功从 1,113 步降到 933 步。

但巩固阶段从 3,218 涨到 3,340，总账因此持平。空间分量在第一次成功之后已经关掉，所以这不是它持续干扰的结果。**更可能的机制是：更快到达终点意味着到达时值表更薄，后续巩固要多花时间。** 这只是一个解释，没有单独验证。

## 5. 三次尝试的合并结论

| 版本 | 相对深度势 | 病因 |
| --- | --- | --- |
| 反向计数 | 0.40 | 第一次成功前没有数据，那一段就是深度势 |
| 向 frontier 反向可达 | 0.41 | frontier 成为吸引子，首次成功反而更慢 |
| guided | 1.01 | 追平，首次成功快 1.19 倍但还回去了 |

**三次都没有缩小到特权乘积势的差距。** 那个差距是 3.74 倍，而三次尝试都停在 1.0 附近。

这条线的诊断从第七步起就没有变过，而且三次尝试都印证了它：**乘积势的优势几乎全部来自"知道到一个从未到达过的目标还有多远"，而这个量从已发现的结构里构造不出来。** 第三版把能构造的部分做到了最好，也只换来首次成功的 1.19 倍，然后被巩固阶段吃掉。

我认为这条线可以停了。继续做的边际收益已经很低，而且不再有新的机制假设。

## 6. 不能说什么

三种设计，不是穷举。空间分量只试了"最近的未试事件"这一种目标选择，深度分量只试了"已见最深加一"这一种乐观估计。两半的尺度只在一个粗网格上选过。全部限于这一族任务、这一族岔路地图、无噪声、表格式。

"更快到达导致值表更薄"只是对持平现象的一个解释，没有做冻结数据对照来验证。
