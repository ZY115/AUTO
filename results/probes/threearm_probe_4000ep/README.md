# 三臂速度探针（book，4,000 幕，1 个种子）

**这是探针，不是结果。** 用途是在投入长网格之前，确认三个臂都能跑通、量一下相对成本。

- Y11 / Y10 / Cfull × safe+lava × 1 个种子 × 10 张地图，4,000 幕
- 跑于 2026-09-13 本机

## 这批数据支持过一个后来被更正的数字

当时据此报过「C-full 约 2.3–3.8 倍墙钟」。**那个比法是错的**：它在固定*幕数*下比，
而两臂每幕的环境步数不同，数字被稀释了。固定*环境步数*重测后，本机 book 上是
**3.36 倍**（见 `local_lava_10m.md`）。

另外这批数据里 safe 那格两个快臂都贴在可测下界上（末端定义下最早可报 1,000 幕），
所以「Y11 与 Cfull 无差别」这个读法当时也不成立——那是分辨率不够，不是没差别。
后续的 `safe_probe_4000ep` 用密集评估解决了这个问题。
