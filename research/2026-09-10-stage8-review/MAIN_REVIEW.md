# Stage 8 最新实验与相关文献审阅

审阅日期：2026-09-10。重点：Stage 8 STEP8–STEP16，尤其 STEP15–16 的目标条件技能、反事实经验和模型修订。本文是资料审阅与研究判断；未修改原实验程序、原报告或原始结果。仅在独立目录运行一个已有训练条件的复现及小型诊断。

## 1. 判断

**方向没有走偏，但“要证明的东西”需要收紧。** 新结果显示，把进展知识用于选择可复用的目标技能，在现有可逆任务族上比若干任务状态索引方案快很多。这是有价值的机制观察。不过，目前不能据此宣称新的自动机利用范式、胜过 JIRP，或已经验证了不可逆条件下不确定结构的损失机制。

最有希望继续追问的是：**从有限交互获得的任务结构，在跨地图与不可逆决策中，究竟哪些部分可以立即使用，哪些需要验证；怎样利用它而不过度相信它。** 这是候选问题，不是本轮批准或执行的实验计划，更不是已经建立的新颖性结论。

“学习完整自动机”也不应是默认终点。若一个进展历史到目标的字典已能达到同样效果，就应接受这个结果。完整结构只有在未见历史、结构迁移、长期规划或风险判断上提供额外作用，才需要为它付出归纳成本。

### 2.1 可逆任务上的信号很强，但归因仍需克制

STEP16：12 个任务 × 16 种子，每臂 192 条运行，预算 100,000。表中达标步数使用原报告口径：未达标按预算截尾。

| 实现 | 平均首次达标步数 | AUC | 最终达标 |
|---|---:|---:|---:|
| oracle 任务索引，普通更新 | 12,604 | 0.9017 | 192/192 |
| oracle 任务索引，增加普通回放 | 6,333 | 0.9537 | 192/192 |
| oracle 任务索引，CRM | 5,012 | 0.9589 | 192/192 |
| 学到的合并状态，普通更新 | 25,255 | 0.8442 | 182/192 |
| 学到的合并状态，当前 CRM 实现 | 30,585 | 0.8478 | 160/192 |
| oracle 目标选择，`relabel=0` | 1,653 | 0.9875 | 192/192 |
| oracle 目标选择，全目标更新 | 739 | 0.9948 | 192/192 |
| 学到的目标选择，全目标更新 | 838 | 0.9935 | 192/192 |

**6.78 倍是 oracle 目标选择相对 oracle CRM 的观测比值。** 它不是“学出的完整自动机比已有最强方法快 6.78 倍”。838 步的 learned 结果同样值得保留，但该路由器实际使用前缀节点上的事件进展频率，不读取合并后的全局自动机，见下文。

当前比较同时改变了目标奖励、终止条件、跨任务状态共享和高层动作选择。因此可以说“目标技能方案的整体包有效”，尚不能精确说“单独改读法贡献 3.03 倍，重标记独立贡献 2.24 倍”。更新次数对齐只能排除一种计算量解释，不能完成全部机制分解。

STEP15 的最终平均路线长度约为索引 20.5、oracle 目标 21.2、learned 目标 22.8。此处有速度与路线质量的权衡，但它首先是**当前贪心路由和技能库**的权衡；不是目标分解必然短视的定理。[LOF](https://proceedings.mlr.press/v139/araki21a.html) 提供了选项层规划的直接参照。

### 2.2 跨地图：已经测过，当前证据偏弱

STEP9 的扩大样本结果是约 1.08 倍、报告区间 [0.95, 1.24]，不能称为稳定迁移收益。25 对源/目标图中有地图复用，显著性不能简单把种子或全部图对当成独立样本。源阶段还需计入成本。

但 STEP9 主要研究的是任务状态索引与合并。STEP15 改成目标技能后，**这套新利用方式的“只迁移任务知识、目标图重新学习导航”仍未由现有结果充分验证**。不能拿旧负结果宣布新机制也无效，也不能拿 838 步的同图学习结果当迁移证据。

TALearner 的环境偏差问题说明了这里为什么有意义：源图上足够的规则不一定是地图无关规则。不过本项目有显式 progress 反馈，比仅终局奖励包含更多信息，需在相同反馈条件下检验歧义。[TALearner](https://arxiv.org/abs/2208.11838)

### 2.3 不可逆结果：保留原始记录，暂停机制性结论

STEP15 fatal 数据中的 AUC、达标速度和最终成功率是该程序的实际输出。问题是程序并未干净地隔离“不可逆性”：失败后继续产生的数据，被错误地归入失败前的任务历史，还反复累计失败。因此“塌了 10 倍”“浪费了多少步”“置信度救不回来”不能直接解释为结构不确定性的固有代价。

这不是要求撤销全部 Stage 8。最直接受影响的是失败后继续运行的条件，以及基于这些条件的风险/置信度归因。可逆任务的技能优势并未被这个见证否定。

## 3. 需要先修正的证据边界

### A. 失败后历史不充分，且计数有误（已独立复现）

[compress.cpp](</Users/yuhang/Downloads/why TL/AUTO/research/2026-09-10-stage8-review/audit/snapshot/src/compress.cpp:1298>) 约 1298–1365 行：进入失败状态不算 progress，`hist` 与 `node` 保留失败前的值；但失败后每一步仍更新 `ignored`、任务 Q 和 danger。`Encoder` 由进展历史重建状态，所以连普通 oracle 索引臂也会把失败后的训练更新映射到健康任务状态。纯物理导航技能与任务索引 Q 因而受到不同影响。

已有条件 `taskR_00_fatal / seed 5000 / goal_learned / budget 200000` 的复现：

| 量 | 结果 |
|---|---:|
| 真正进入失败状态 | 65 |
| 失败后的物理步 | 1,797 |
| 原程序 `failures` | 1,862 = 65 + 1,797 |
| 原程序 `doomed_steps` | 26,525 |
| 失败后写入健康历史的事件 | 1,766 |
| 与此前进展记录冲突的事件 | 738 |

原 `doomed_steps` 在失败状态的每一步都加剩余时长，重复累计；不是实际耗费步数。诊断副本仅增加计数，**全部输出字段与原程序逐项相同**，并复现保存的 AUC、final、failures、doomed、nodes。见 [irreversible_witness.json](</Users/yuhang/Downloads/why TL/AUTO/research/2026-09-10-stage8-review/audit/irreversible_witness.json>)。

应先明确失败信号是否对学习器可见：若可见，历史必须区分失败状态；若不可见，就不能一边把真实 dead 用于 Bellman 终止，一边把这段经验当健康历史证据。两种设定都可以研究，但不能混在一起。

### B. “JIRP” 是近似对照，不是忠实 JIRP

约 829–884 行用三轮签名传播近似未来等价，重复旧签名还会导致不迁移；旧、新分区的签名都根据当前树证据构造。原文 Definition 4 和 Algorithm 4 要求新旧假设状态对所有未来串输出相同。[JIRP 扩展稿](https://arxiv.org/abs/1909.05912)

三轮方法无法看到长度 4 以后才出现的区别，见 [signature_witness.json](</Users/yuhang/Downloads/why TL/AUTO/research/2026-09-10-stage8-review/audit/signature_witness.json>)。所以“member transfer 比 JIRP 快 1.68 倍”应改成“比当前三轮签名迁移器快”；精确等价需要保存旧假设并独立验证。

### C. `relabel=0` 没有保存当时的目标（已构造执行见证）

`Raw` 没有 `active_goal`。约 578–586 行回放时重新调用 `select_goal`，使用更新后的技能值；因此同一条经验可能训练另一个目标。诊断直接调用原始类：采集时目标 0，改变技能值后，同一 Raw 在 `relabel=false` 下更新目标 1。见 [goal_replay_witness.json](</Users/yuhang/Downloads/why TL/AUTO/research/2026-09-10-stage8-review/audit/goal_replay_witness.json>)。

这不否定 1,653 步是当前实现的表现，但它不支持严格的 no-relabel 消融。对 learned 选择器，回放调用还传入 `node=-1`，也不能恢复当时的证据状态。

### D. learned CRM 的负结果有实现层混杂

约 1089–1113 行只选每个合并类的第一个代表节点查询事件证据；类中其他节点见过的事件不一定被利用。未知时直接跳过，而开启 CRM 会替代原始真实经验更新。该分支没有独立表达失败边。

因此 learned CRM 的退化可能同时来自：错误模型传播、代表节点信息缺失、真实更新遗漏和终止语义。最终 precision 相近，不等于两个算法使用了相同模型或相同证据；改变行为还会改变后续数据。当前结果尚不能证明“同样错误结构因为被重复使用而必然更差”。

### E. learned goal 实际是前缀路由器；弱对照不能证明唯一性

约 532–558 行，learned 选择器优先选当前历史节点上最常推进的事件，并在未知时乐观回退。这是有效的历史条件目标路由，但没有使用 `blocks` 的合并结果或全局后缀规划。将它叫作“学习到的任务知识”可以；叫“已恢复并利用完整最小自动机”不准确。

`untried` 则偏好本集未做过的事件，而任务包含重复标签。它的 0/192 不能排除有合适历史记忆的手写目标提供者。一个公平字典基准可能与 learned 路由器本来就是同一算法。

### F. 区间与跨步骤推断应调整

`run_goal_irreversible.py` 的 bootstrap 用 `map in sampled_maps` 聚合，丢掉了重复抽中的地图次数。本轮保留重复次数重算：learned 目标相对 merged 的速度比 2.01，区间约 **[1.46, 2.64]**，原报告为 [1.57, 2.55]。点估计不变；这没有修复失败态语义，见 [corrected_fatal_bootstrap.json](</Users/yuhang/Downloads/why TL/AUTO/research/2026-09-10-stage8-review/audit/corrected_fatal_bootstrap.json>)。

STEP11 按训练结束 precision 是否等于 1 分组，再做替换，不能构成“任何置信度方法至多收益 1.16”的因果上界。最终 precision 是训练和行为的结果，分组混合了任务难度、覆盖和算法效果。

STEP12 的状态数/长度幂律拟合可作局部经验描述，不能据此精确分解新算法的收益。其他函数也拟合得好，说明参数解释不唯一；不能反过来证明某种物理开销绝不存在。

首次达到 90% 与稳定达到 90% 应分开。fatal 条件中，索引臂平均 first90 很低而最终仅部分种子达标，说明“首次碰到阈值”会掩盖退化。后续叙述至少同时保留 AUC、最终成功率和稳定性。

## 4. 文献如何改变贡献定位

最直接的比较不是“TL vs 不用 TL”，而是以下几种结构与控制接口。

| 研究对象 | 最近的先例 | 我们目前站在哪里 |
|---|---|---|
| 从事件轨迹学自动机并选择技能 | ISA、HRM | 概念已有；当前是便宜的前缀事件路由 |
| 从一个物理转移更新多个任务状态 | RM / CRM、JIRP | oracle 对照有用；learned 分支需独立语义核对 |
| 图修订后保留有效策略 | JIRP、ISA 的技能字典 | 当前局部签名不足以做强文献比较 |
| 任务结构与环境分离 | TALearner、C-PREP、FORM | 方向契合；必须说明具体搬了什么 |
| 目标分解同时考虑长期路线 | LOF、Future Dependent Options、空间细分子策略 | 当前贪心选择器遗漏了这类强对照 |
| 不确定条件下使用符号结构 | Noisy RM、Partial Semantics | 标签/状态不确定不等于结构不确定 |
| 不可逆风险下保证安全 | Shielding | 正确模型上界可用，未知结构不能免费继承保证 |

来源与逐篇假设见 [文献索引](</Users/yuhang/Downloads/why TL/AUTO/research/2026-09-10-stage8-review/LITERATURE_INDEX.md>)。其中 [ISA](https://arxiv.org/abs/2009.03855)、[HRM](https://proceedings.mlr.press/v202/furelos-blanco23a.html) 已明确把结构、子目标策略和共享经验连接起来。因此，**“让自动机告诉 RL 下一步目标”不宜成为核心新颖性主张。**

更有机会的三个问题，按与当前证据接近程度排列：

1. **不完整结构的可靠使用。** 区分亲历证据与假设推断；研究在何种决策上允许承诺、何时需要验证、何时保留任务值函数。要与 ISA 式元控制器、朴素字典和简单保守策略比较。
2. **严格的结构迁移。** 固定任务语义，重置目标图的地图模型、导航技能和值函数，只迁移可解释的任务知识；与迁移原始轨迹/前缀字典比较，并计入源图采样成本。若压缩图不能胜过同证据字典，应报告其边界。
3. **目标实例与后缀成本。** 多个同标签实例中，最近目标可能把人送到昂贵或危险的位置。先用选项模型规划解释当前路线损失，再考虑有选择地扩充技能库。[空间子策略论文](https://openreview.net/pdf/c33d0d4c87e2287631c3d7012fb4eaf5cddf5eb5.pdf)

还有一个直接先例需要特别强调：[Future Dependent Options（Machine Learning 2024）](https://link.springer.com/article/10.1007/s10994-024-06614-y) 已让技能依赖未来子目标，用来处理同一标签对应多个位置的问题。因此“给技能加后缀条件”本身也不是空白；更具体的候选空间是后缀来自不完整、可能出错的任务知识时怎么办。

这三者可以关联，但不宜同时把未知规则、未知标签、未知地图、随机动力学和风险全加进去。当前研究对象最清晰的版本是：**已知事件语义，任务结构逐步发现，地图知识独立学习。**

## 5. 能直接使用哪些工具

- **AALpy：已经做独立接口试验。** 1.6.2 的默认 GSM，在一个包含 progress/ignored/success/failure 四类输出的 Mealy 例子中，62 条训练词得到 4 状态机；枚举长度至 7 的 254 条词，0 不一致。classic 路径在同例子只保留前缀树，长词有未定义转移；原因尚未定位，不能称所有实现都已通过。系统 Python 3.9 导入失败，改用本机 bundled Python 后运行。它现在适合做被动学习的独立对照，不代表已完成 Stage 8 复现。[AALpy](https://github.com/DES-Lab/AALpy)

- **LOF / SF-FSA-VI：规划参考。** 要吸收的是选项成本、终止位置与长期任务价值，而不一定立刻迁移到大型神经环境。

## 6. 讨论下一步之前应共同接受的结论

可以继续保留：可逆任务上的目标技能整体优势；历史压缩有条件收益；单图证据可能不足以迁移；结构修订值得与策略知识复用一起研究。

需要降格或撤回：完整自动机的唯一必要性、置信度收益的普遍上界、目标分解的必然短视、当前近似基准代表 JIRP，以及未排除失败态污染的不可逆因果解释。

**我建议优先围绕“什么任务知识值得信任和迁移”讨论下一步，而不是继续扩大压缩比扫描。** 但在决定新算法前，先把上述三个实现见证和文献强基准纳入判断；否则更多数据可能只会把混杂因素估得更精确。
