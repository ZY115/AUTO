RL       reinforcement learning                    A method for agent learning through experiencing the world, acting within it,
                                                   and receiving rewards for achieving certain states or state transitions.
DRL      deep reinforcement learning               RL using deep learning methods.
TL       transfer learning                         The improvement of learning a new task through the transfer of knowledge from
                                                   a related task that has already been learned.
MDP      Markov decision process                   A world model used commonly in RL, defined as a 5-tuple ⟨S, A, T, R, γ⟩ .
CMDP     contextual Markov decision process        A collection of MDPs identified by contexts, defined as a 4-tuple ⟨C, S, A, M⟩.
VI       value iteration                           A dynamic programming algorithm for estimating the optimal state-value func-
                                                   tion in an MDP.
RM       reward machine                            A state machine abstractions of an MDP, defined as a 3-tuple ⟨U, δu , δr ⟩.
CTL      controllable context representation       A context representation that includes the necessary information to generate the
                                                   MDP.
PCG      procedural content generation context     A context representation that conceals the MDP variables and only reveals infor-
         representation                            mation about the context identity.
LTL      last transition label                     A configuration of the learning algorithm using the RM transition label mapped
                                                   from the previous MDP transition.
DTL      desired transition label                  A configuration of the learning algorithm using the transition label that leads to
                                                   an optimal transition within the RM.
RS       reward shaping                            A configuration of the learning algorithm using potential-based reward shaping
                                                   based on an RM.
C-PREP   contextual pre-planning                   The method presented in this work, whose configuration is DTL+RS.
GN       Grid Navigation                           An environment where the agent must navigate to a specific location and declare
                                                   “done”.
MP       multi points-of-interest                  An environment where the agent must navigate to multiple locations in no par-
                                                   ticular order, declaring arrival at each location.
PD       pick-up and drop-off                      An environment where the agent must pick up and drop off passengers at their
                                                   desired destinations.
ON       ordered navigation                        An environment where the agent must navigate to multiple locations in a specific
                                                   order, declaring arrival at each location.
EL       entity location                           A context space where contexts affect the location of entities on the map (eg.,
                                                   points-of-interest and passenger destinations)
CM       changing map                              A context space where contexts affect the location of obstacles on the map.
PO       points-of-interest order                  A context space for the ON environment where contexts affect the order by which
                                                   the points-of-interest must be visited.
